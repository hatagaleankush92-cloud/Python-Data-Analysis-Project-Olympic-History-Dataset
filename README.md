# Python-Data-Analysis-Project-Olympic-History-Dataset
Python-based analysis of the 120 Years of Olympic History dataset using Pandas and NumPy in Jupyter Notebook.

📌 About This Project
This project explores 120 years of Olympic athlete data using Python (Pandas & NumPy only) in a Jupyter Notebook environment.
The goal was to perform complete data analysis — including cleaning, transformation, and statistical insights — without using visualization or machine learning libraries.

🎯 Project Objectives
Clean and preprocess raw Olympic data
Analyze athlete participation trends
Study medal distribution by country and gender
Compare age patterns of medalists vs non-medalists
Perform sport-wise and year-wise analysis

🛠 Tools Used
Python
Pandas
NumPy
Jupyter Notebook

📊 Key Insights
A small group of countries dominate total medal counts
Male participation historically exceeded female participation
Medal-winning athletes have slightly different age trends
Athletics and Swimming contribute the highest medal counts

📂 Dataset Information
Dataset: 120 Years of Olympic History — Athletes & Results
Source: Kaggle
File Used: athlete_events.csv
