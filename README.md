# Python-Data-Analysis-Project-Olympic-History-Dataset
Python-based analysis of the 120 Years of Olympic History dataset using Pandas and NumPy in Jupyter Notebook.

Project Overview
This project analyzes the 120 Years of Olympic History (1896–2016) dataset using Python in a Jupyter Notebook environment. The analysis focuses on data cleaning, transformation, and extracting meaningful insights using only Pandas and NumPy.

Objectives
Clean and preprocess historical Olympic data
Analyze athlete participation trends
Examine medal distribution by country and gender
Perform statistical analysis on age and performance
Identify sport-wise and year-wise trends

Tools & Technologies
Python
Pandas
NumPy
Jupyter Notebook

Key Analysis Areas
Total athlete participation across Olympic editions
Medal count by country and sport
Gender participation trends
Average age analysis of medalists vs non-medalists
Year-wise performance patterns

Outcome
The project demonstrates fundamental data analysis skills, including data cleaning, grouping, aggregation, and statistical computation without using visualization or machine learning libraries.
